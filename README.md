# Address Book Management System

## Project Description

A contact management application developed using C programming. It allows users to efficiently manage and maintain contact information.

## Technologies Used

* C Programming
* Structures
* File Handling

## Features

* Create new contacts
* Search existing contacts
* Edit contact details
* Delete contacts
* Display all saved contacts
* Save and retrieve contact information using file handling

## How to Run

1. Clone this repository.
2. Open the project folder in your terminal.
3. Compile the source files using GCC.
4. Execute the generated executable file.

## Concepts Implemented

* Structures
* Functions
* Arrays
* File Operations
* Input Validation
